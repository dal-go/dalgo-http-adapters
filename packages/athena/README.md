# Native Amazon Athena reads

This private source package adds reads of explicitly configured **existing native tables**, without a managed JSON envelope. It compiles the ordinary DALgo structured query into one closed SELECT and provides public same-execution native pages. This is a source implementation awaiting independent qualification; it is not a registry release, AWS account/IAM/S3 authorization, scan-cost guarantee, live Athena result proof, or browser CORS proof.

The pure root exports `AthenaNativeClient`, native types, `AthenaDatabase` and safe errors. `./node` alone imports Node crypto and the official Smithy SigV4 signer. `./http` exports the authenticated application handler; `./browser` exports the application-bridge client and never accepts AWS credentials. Node22 is the advertised minimum; the actual qualified runtime must be recorded by the controller rather than inferred from that floor.

## Existing data and exact values

A trusted source fixes sourceId, AWS region, workgroup, catalog, database, result S3 prefix, expected bucket owner/encryption and a finite map of native table/column names/types. Constructor performs no credential acquisition or network request. Trusted transports attest principal and generation; token presence is not identity. The Node factory takes an explicit credential callback; it never discovers profiles, environment credentials, IMDS, accounts or broader grants.

`queryPage(query, {signal,pageSize,projection,offset})` returns ordered `columns`, `rows:string|null[][]`, absolute `ordinalStart`, `hasMore`, optional `nextCursor` and a receipt. `nextPage(cursor, signal)` reads that same execution; it does not resubmit SQL. Caller query IDs and raw Athena NextToken values cannot be adopted. Missing values/omitted trailing cells are NULL; empty strings remain empty. Extra cells, changed column metadata and repeated tokens fail. The initial SELECT header is consumed once, even across header-only/empty nonterminal pages. Equal-valued data rows are legitimate and are retained. Integers, decimals, exponents, temporal precision, binary and complex Athena values remain their original text alongside native metadata; the adapter does not guess a binary encoding or coerce to JavaScript Number/Date. DataScannedInBytes retains an exact nonnegative integer string when provided, and is absent rather than invented zero otherwise.

The configured optional non-null unique **string** idColumn enables the core facade. `get`/`exists` check up to two matching rows; a duplicate/mismatched key is an error. `getMany` snapshots all keys before callbacks and shares one original scope and aggregate budgets, preserving duplicate/missing order and independent data objects. Without an id mapping, use ordinal native pages; no fake record keys are minted. Keyed core `query` materializes the bounded query; native `queryPage/nextPage` is the continuation API, not a document startAfter key. Operator-declared uniqueness is not inferred to be enforced by Athena.

## Closed SQL and request bounds

The compiler supports configured scalar columns, explicit native projection, comparisons, IN/NOT IN, null predicates, conjunction, ASC/DESC order, bounded LIMIT and **OFFSET**. Numeric values can be exact decimal strings for configured numeric columns. String parameters receive SQL apostrophe escaping; only generated literal expressions enter positional ExecutionParameters. Placeholders occur only in generated WHERE predicates. This is the adapter subset, not a claim that the API universally forbids other parameter positions. The AWS console's25-question-mark limit is not asserted as an API count limit.

OFFSET is a validated nonnegative safe integer, maximum100000, rendered once into the original SQL before LIMIT. It is never implemented by client row-dropping or reapplied on nextPage. Native ReadOptions offset and ordinary query.offset must not conflict. Unknown AST constructs, parent keys, document cursors, arbitrary SQL, joins/computed/grouped SQL, writes, schema discovery and transactional callbacks are not implemented; many are provider capabilities and are not described as intrinsically unsupported.

Defaults: original operation30s (maximum120s), pageSize100 (1..1000),10000 cumulative data rows,100 result-page requests,100 polls,512 total requests/attempts,64KiB per request,1MiB aggregate request bodies,4MiB per response,32MiB aggregate received header/body bytes,8192 parse nodes per response and65536 cumulative parse nodes,256 columns and64 parameters. A parameter's generated expression is at most1024 UTF-16 code units. Limits are adapter admission bounds and not engine working-memory or billing caps. HTTP bodies are bounded as delivered/decompressed by the transport, not TLS/network framing overhead. Already allocated buffers in a caller's borrowed dependency cannot be retrospectively bounded. The owned Node path supplies raw streams before JSON decoding.

Each explicit query LIMIT is enforced across that execution independently of the shared core-batch row budget. A provider over-return fails before staging a deliverable page or invoking its response factory; earlier acknowledged pages remain explicitly incomplete. Whole bounded service pages are returned or refused. A header-only/short/empty page with a token is not EOF. A later limit error does not erase earlier acknowledged pages: their receipts explicitly say incomplete. No successful truncated full-query result is fabricated. GetMany returns no successful prefix on later failure.

## Authority, deadlines and native ACK

All input copies, credential waits, signing, submit/poll/page reads, codecs and response construction share the original monotonic deadline. Native AbortSignal state/listeners are captured intrinsically; foreign methods on the exposed signal cannot replace the private race. Uncooperative credential/send/read/cancel work continues to hold finite admission until physical settlement. A borrowed client/transport is never destroyed. Reader cancellation starts under lock ownership; its promise is observed without blocking public cancellation, while its physical lease stays retained.

Each new query has a fresh random32..128-character idempotency token. Unknown submission is not retried and does not fall back to an old token. QUEUED/RUNNING transitions may reverse; FAILED is terminal. At most one StopQueryExecution is attempted for the captured owned ID, using only its captured submit authority and a separate private2s cleanup scope.200/empty means cancel requested, not observed CANCELLED. Unknown ID, expired authority, failed or stalled stop remains unknown; no new credential/principal fallback occurs. Local cancellation/Close cannot promise remote compute or charges stopped. Short-process shutdown can interrupt cleanup; this SDK does not claim a joined process shutdown API.

An opaque cursor binds this client instance, admitted source/config/query/offset/pageSize, principal/generation, execution, schema, ordinal and original expiry. Original deadline and fixed TTL (default/max120s, earlier query deadline wins) are never renewed. A private busy lease spans public return through physical dependency/cleanup completion. Pending native pages are retained under the client-wide logical journal quota after failed delivery, so retrying the prior handle cannot replace the failed page or repeat acknowledged rows. Callback return values are fresh copies. No fallible callback or await runs after the final native ACK.

The global logical pool defaults/max16MiB and65536 nodes, with128 journeys (hard1000). Each journey conservatively reserves65,536 logical bytes and64 nodes for captured signing authority, including the Node path's maximum32KiB session token and admitted identity fields. Resumed work reserves a second such charge until all physical work settles; its original submit credential remains captured for an owned Stop. The client keeps only a frozen principal/generation copy. A trusted custom transport can implement captureAuthority(original, admitted) to bind private signing state to that copy, and must keep its retained state per admitted authority within that bound. Extra graphs on the callback's original object are not retained by the journal. Caller-owned global caches and allocations inside borrowed dependencies remain outside this logical pool. Full pending-page reservation plus fixed journal/metadata charges is admitted before dispatch; options incompatible with that pool refuse. Net replacement is atomic at ACK. Expiry/Close retire authority immediately, with lazy pruning on another operation and exact refund only after public completion plus physical settlement. This is not a process-heap bound. Replay, concurrent same-handle work and foreign-instance/principal handles refuse. Durable/cross-process sessions, portable cursors and arbitrary existing-query adoption remain not implemented.

Codecs and response factories can perform external side effects that the adapter cannot undo. Registry rollback protects local page authority and acknowledgement, not arbitrary caller effects. Synchronous callbacks cannot be safely preempted; JavaScript callbacks are awaited; the adapter cannot bound arbitrary allocation or external side effects inside a caller codec. Native returned values are admitted before those callbacks.

## Workgroup, S3 and cost

A read-only GetWorkGroup preflight requires an enabled SQLengine2+ profile, enforced configuration, cutoff at least10000000 and not above the configured maximum, exact approved S3 output/owner/encryption, and no managed-results/Identity Center mode this profile has not qualified. It never creates or updates a workgroup. Query execution identity/context/workgroup/output are checked. A preflight-to-execution configuration race remains; these checks do not prove IAM or a pre-execution billing ceiling. Result reuse is explicitly disabled. External catalog/federation eligibility and extra service charges are not qualified by the owned fixture.

A principal that has S3 GetObject may read result objects despite denial of Athena GetQueryResults. Actual IAM, Lake Formation, S3/KMS and result storage permissions must be reviewed together by the account owner. No direct S3 read fallback exists. Observed scanned bytes are not an authorization, price, invoice or session billing reservation. This is not BigQuery dry-run/maximumBytesBilled or paid-approval ledger behavior.

## Application bridge and proof scope

The handler requires an explicit allowed Origin plus application authentication/CSRF/principal/source-policy authorization, supplied by a trusted authorize callback. It accepts only closed query/next descriptors. The hosting layer must propagate actual upload/disconnect to Request.signal. The same native staged primitive awaits serialization, Response construction and outer cleanup before committing a cursor. A failed factory preserves the input cursor. A connection failure after server ACK is an **unknown delivery outcome**, not proof a browser received the rows; no exactly-once network delivery is promised.

The source tests include synthetic official-SigV4 requests with independently checked HMACs over a fixed-authority trusted-fetch loopback HTTP seam, actual dispatch/caller/deadline/disconnect/reopen and positive socket cleanup. This is not default AWS TLS, Athena engine, IAM/S3, hosted cost or actual browser query proof. Browser graph checks show import separation only. Normal source pack/module public dependencies, strict Node/DOM declarations and runtime checks must be qualified independently in the controller.
